# CodeViz 视觉与交互设计简报（v1）

> ui-dev / viz-dev 共同遵守。目标：**看起来像一件被认真设计过的教学产品**，而不是模板堆砌。
> 设计关键词：**工程图纸的精确 × 现代学习产品的亲和**。冷静、清晰、有手绘图解的温度。

## 1. 品牌

- 名称：**CodeViz · C/C++ 图解工坊**
- Slogan：**看得见的 C / C++**
- 首页主标题：**把 C / C++ 代码，变成看得见的图。**
- Logo：圆角方形底（indigo→sky 轻渐变）内白色 `C` 字形与三个节点连线（见 `public/favicon.svg`，可在 UI 里做同款 SVG）。
- 语气：中文，简洁、鼓励式、无术语炫技；称呼“你”。

## 2. 视觉语言

- 浅色为主（默认跟随系统，可切换深色）。页面像一张浅灰蓝的纸：`#f6f7fb`，卡片纯白，1px 冷灰描边，阴影克制。
- 背景可用极淡的点阵（`radial-gradient` 点，透明度 0.3），只出现在 hero 与空状态区域，不要铺满整个应用。
- 主色 indigo `#4f46e5`，辅助 teal `#0d9488`、amber `#d97706`、rose `#e11d48`、sky `#0284c7`、violet `#7c3aed`。这些颜色在图表中承担语义：**判断/条件=amber，循环=teal，处理=indigo，输入输出=rose，调用=sky，结构/类=violet**。
- 代码区域深色（`#0e1526`），与浅色页面形成明确分区，是产品的“工作台”质感。
- 圆角：卡片 16px、按钮 10px、小标签 999px。阴影最多到 `0 24px 60px -32px rgba(15,23,42,.28)`，不要发光/玻璃拟态。
- 动效：入场 300–450ms `cubic-bezier(.22,1,.36,1)`，位移 ≤ 12px；hover 抬升 2px；图表节点 hover 轻微变色；播放器脉冲。尊重 `prefers-reduced-motion`。
- 图标：一手绘制的线性 SVG（24×24，stroke 1.8，圆头），禁止 emoji 充当功能图标。至少需要：home, book, flask/beaker, map/nodes, info, sun, moon, menu, close, upload, play, pause, step-forward, step-back, skip-start, skip-end, copy, check, arrow-right, chevron-down, chevron-right, code, flow, call, class, memory, trace, warning, sparkle, search, zoom-in, zoom-out, reset, download, link, clock, target, lightbulb。

## 4. 应用外壳

- 固定左侧栏 264px（浅色卡片感或与背景同色 + 右边线），内含：
  - 顶部 Logo + “CodeViz” + “C/C++ 图解工坊”两行品牌块；
  - 主导航：首页 / 教程 / 实验室 / 知识图谱 / 关于（选中项：indigo 软底 + 左侧 3px 竖条 / 或实底，二选一统一）；
  - “学习进度”小节：4 个章节，显示章节名 + `已完成/总数` + 细进度条，可点击进入该章第一课；
  - 底部：主题切换（太阳/月亮 + 文案）+ 版本 `v1.0` + 一句 “纯本地分析 · 数据不出浏览器”。
- 主内容区顶部：移动端显示 sticky 顶栏（Logo + 菜单按钮）；桌面端页面自己带头部，不加全局顶栏。
- 页面内容宽度：普通页 `max-width: 1180px`，课程正文 `760px + 240px 目录`，实验室全宽（左右分栏，最大 1600px）。
- 移动端（<960px）：侧栏改为抽屉（遮罩 + 滑入），页面内边距 20px；课程目录折叠为“本节目录”块；实验室上下堆叠。

## 5. 页面逐页规格

### 5.1 首页 `#/`

1. **Hero**（两栏，左 54% / 右 46%）：
   - 眉标 chip：`为 C/C++ 初学者设计`（indigo 软底、小圆点）。
   - H1：`把 C / C++ 代码，`换行`变成看得见的图。` “看得见的图”可用深 indigo 或在文字下方加一条手绘感下划线 SVG。
   - 段落：上传 1000 行以内的代码，立刻得到流程图、调用图、类图、内存布局与单步执行动画——抽象概念第一次变得触手可及。
   - 按钮：`开始学习`（primary，箭头）/ `打开代码实验室`（secondary，烧瓶图标）。下方一行 meta：“13 节课程 · 30+ 示例 · 全程本地分析”。
   - 右侧视觉：叠层卡片。后层深色代码卡（`for (int i = 0; i < n; i++)`、`if (a[i] > max)` 等 6–8 行 C 代码，真实语法着色），前层白底流程图小卡：`开始 → [i < n?] → 是 → 处理 a[i] → 返回判断 → 否 → 结束`，用 indigo/teal/amber 节点与手绘箭头；再飘两个小 badge（“判断 · 分支”“循环 · 回边”）。可用 CSS 缓慢漂浮，禁止大幅动效。整体放在带点阵和柔和 radial glow 的容器里。
2. **能力卡片区**（标题“六个视角，拆开一段代码”）：4–6 张卡，每张：线性图标、标题、两句描述。至少：`函数流程图`、`调用关系图`、`类与对象图`、`内存布局`、`单步执行`、`代码体检`。卡片 hover 轻微上移，图标底色用对应语义软色。
3. **学习路径**：4 个章节横向/纵向卡片（按屏幕），每章：编号 `01`、章节名、副标题、lesson 列表（可点击）、进度环或进度条。卡片顶边用章节色调。
4. **实验室预览**：左侧说明 + 3 个可点击示例卡片（冒泡排序 / 递归阶乘 / 多态图形），右侧一个示意面板（统计数字 + 迷你流程图）。按钮“在实验室打开全部示例”。
5. **参考说明条**：小字注明课程脉络参考两本教材，所有讲解/代码原创；链接到关于页。
6. **底部 CTA**：深色 indigo 卡片，“写下的每一行，都值得被看见。” + 开始学习按钮。

### 5.2 课程目录 `#/learn`

- 页头：eyebrow `CURRICULUM`，标题“课程”，说明：从第一行 `printf` 到多态，13 节课把 C/C++ 的核心概念画出来。右侧显示总进度环 + “已完成 x / 13”。
- 每章一个 section：左侧章节标识（编号、章节名、副标题，章节色），右侧 lesson 卡片列表（2–3 列网格）。卡片含：序号（等宽小字）、标题、description、meta（分钟 · 难度 · 小节数/测验数）、右上角完成勾选。hover 抬升。
- 卡片可整卡点击；键盘可聚焦。
- 底部“从代码实验室开始”的次级横幅。

### 5.3 课程详情 `#/learn/:id`

- 顶部面包屑：教程 / 章节名 / 课程名。
- 头部：章节 badge（章节色）、大标题、副标题、meta：难度、约 x 分钟、x 道测验、示例代码按钮。右侧可选小插画/大号章节序号。
- 学习目标卡（浅 indigo 底）：标题“本节你将掌握”，3–5 条勾选式列表。
- 正文两栏：主栏最大 760px；右侧 sticky 目录 240px。
  - 章节标题（`heading` block）生成目录项与锚点；滚动时高亮当前小节。
  - 段落、列表、提示框、表格、代码块、图形卡的间距：块间距 24px，标题上间距 44px。
  - 代码块：深色卡，顶部文件名/语言、右侧复制 + “在实验室打开”；行高亮用 indigo 透明条 + 左侧 2px 亮条。
  - 图形卡：白卡，顶部标题 + 说明，内容即 `AnalyzedDiagram`；底部可有“交互提示：点击节点可定位代码”。
  - `compare`：两栏代码卡，窄屏变上下。
  - `steps`：左侧编号圆点 + 竖线的时间线。
  - `try`：teal 软底卡，提示语 + 按钮“在实验室打开这段代码”。
- 文章底部：关键要点卡（keyPoints）、测验区（quiz card）、上一课/下一课导航；右侧目录底部有“标记本节完成”按钮（完成后变绿）。
- 阅读进度条固定在内容顶部或页面顶部（细 3px indigo）。

### 5.4 代码实验室 `#/lab`

- 页头：eyebrow `LABORATORY`，标题“代码实验室”，说明“粘贴或上传 ≤ 1000 行 C/C++ 代码，从六个视角拆解它”。右侧：示例库按钮（网格图标）、上传按钮（primary）。
- **工具条**：左侧文件名 chip（`.c`/`.cpp` 语言色块、名称、行数/1000；超过 1000 显示红色）；中间状态（未分析/分析中…/已分析 9 个函数 · 0 个错误）；右侧按钮：`分析代码`（primary，Ctrl+Enter）、`执行追踪`（secondary，play）。
- **主工作区** 两栏（≥1180px），左 46% 编辑器，右 54% 分析面板；高度用 `calc(100vh - 210px)` 左右，最小 560px。
  - 左卡：mac 风格三圆点 + 文件标签（可关闭？不需要）+ 行数小字；CodeMirror 编辑器填满，行号、语法高亮、括号匹配、当前行高亮。底部提示条：`Ctrl+Enter 分析 · 支持拖拽 .c / .cpp / .h 文件`。
  - 拖拽文件到编辑器显示覆盖层（虚线边框 + 上传图标 + “松开以载入代码”）。
  - 右卡：顶部 segmented tabs（概览 / 流程图 / 调用图 / 类图 / 内存 / 单步执行 / 诊断），可横向滚动；每个 tab 可带小计数 badge（如诊断数量、函数数量）。内容区独立滚动。
  - 概览：4 个统计 tile（行数、函数、循环、诊断）+ 代码画像（难度徽章、圈复杂度进度条、嵌套深度）；函数列表（名称、行数、复杂度、递归标记），点击切到流程图；调用摘要（入口、调用数、外部函数 chips）；提示“点击图表节点可在编辑器中定位代码”。
  - 流程图：函数选择 chips（全部函数）+ `FlowchartView`（带缩放 +/− 与重置，图例），点击节点高亮编辑器对应行并显示代码片段条。
  - 调用图：`CallGraphView` + 侧边图例；点击节点显示函数小卡（签名、行号、复杂度、是否递归）。
  - 类图：`ClassDiagramView` 或空状态“这段代码还没有定义 class / struct”。
  - 内存：`MemoryView` + 说明“按定义静态估算，非运行期真实地址”。
  - 单步执行：未运行时显示说明卡（支持范围 + “运行追踪”按钮 + 可选 stdin 输入框，多行输入用 “输入数据” textarea，仅在需要时展开）；运行后显示 `TracePlayer`，顶部返回/重新运行；错误/不支持时友好说明。
  - 诊断：按 severity 分组或排序，每条含图标、消息、行号 chip、hint；点击跳转行。空状态“很好，没有发现明显问题”。
  - 面板初始空状态：一个简洁插画（代码→图）+ “点击「分析代码」生成六种视图” + 快捷键提示。
- **示例库 Modal**：标题“示例库”，搜索框 + 语言筛选（全部/C/C++）+ 标签 chips；卡片网格，每张显示标题、description、语言/难度、focus 图标；点击载入代码并关闭。ESC 关闭，焦点管理。
- 上传行为：`<input type=file accept=".c,.cpp,.cc,.cxx,.h,.hpp,.txt">`；读取失败 / >1000 行 / 空文件 → toast 错误；成功 → 自动分析 + toast“已载入 xxx”。
- Toast 右下角，3 秒消失，可堆叠不超过 3 条。
- 本地草稿：每次编辑 800ms 防抖写 localStorage；刷新恢复；页头提供“重置为示例”或工具条的“示例库”即可，不额外加清空按钮以免误触。

### 5.5 知识图谱 `#/map`

- 页头说明：概念之间的依赖关系，点击任一节点查看定义并跳转课程。
- 主体：左侧大画布（SVG，自适应宽度，高度约 640；移动端改为竖向滚动），右侧 300px 详情卡（默认显示引导文案）。
- 画布：4 个分组背景区块（basics/control/data/cpp，用不同软色、组名标签），节点为圆角胶囊（白色底、1px 边、左侧色点），按 `tier` 分层布局，同层水平排列；边为浅灰曲线，箭头；hover 高亮该节点及邻居、淡化其它；点击选中 → 详情卡显示 label、description、“学习这一节”按钮。顶部图例/筛选 chips 可按组筛选，选中组高亮其它组淡出。
- 详情卡：概念名 + 英文（glossary 里能匹配则展示）+ 描述 + 所属章节 + 相关课程链接。
- 移动端：画布可横向滚动；详情卡移到画布下方。

### 5.6 关于 `#/about`

## 6. 组件与交互细节

- **按钮**：高度 40（md）/32（sm）/48（lg）；primary 实底 indigo，hover 加深 6%，active 下压 1px；secondary 白底 1px 边；ghost 透明 hover 软底。focus-visible：2px indigo 外环 + 2px 偏移。加载中显示 spinner 且禁用。
- **代码块**：深色；行号列右侧 1px 分隔；token 颜色：
  - 关键字 `#c4b5fd`，类型 `#7dd3fc`，函数名 `#93c5fd`，字符串 `#86efac`，数字 `#fcd34d`，注释 `#64748b`（italic），预处理 `#f0abfc`，标点 `#94a3b8`。
  使用自研轻量高亮器（引擎 tokenizer 不对外暴露时，UI/viz 各写一份 C/C++ 正则高亮亦可；注意先转义再包 span，禁止 innerHTML 注入）。
- **卡片**：白底、1px `--line`、圆角 16、无默认阴影；hover 可加 `--shadow-md` 与 `translateY(-2px)`（仅可点击卡片）。
- **标签**：small pill，soft 底 + 深色文字；语言标签 `C` 用 indigo，`C++` 用 violet。
- **进度**：课程完成存 localStorage；进度条圆角、indigo；完成态用 teal + 勾。
- **Toast**：深色/白底？用深墨色卡片 `#0f172a` 白字，左下角图标（成功 teal、错误 rose），右下角固定。
- **空状态**：线性小插图（SVG 60–120px）+ 一句主文案 + 可选按钮，留白充足。
- **表格**：表头浅灰底、行分隔线；移动端横向滚动。
- **测验**：选项为整行按钮，字母圆标；选择后未判分前可改；点击“查看答案”后正确项 teal 底+勾，错误选择 rose 底，解析区淡入；全部答完后显示得分与“再试一次”。
- **滚动条**：细（8px），thumb `--line-strong`，hover 加深；仅 Webkit + Firefox。
- **焦点与可达性**：所有交互元素键盘可达；图形 SVG 节点 `role="button"` + `tabIndex=0` + Enter/Space；图表配 `aria-label`；颜色不是唯一信息载体（节点形状/文字同时区分）；对比度满足 WCAG AA。
- **响应式**：断点 1280 / 1024 / 960 / 720 / 520。实验室在 <1180 上下堆叠，编辑器高 420；课程右目录在 <1100 隐藏（改为顶部折叠目录）。

## 7. 数据与状态约定

## 8. 图形组件视觉规范（viz-dev）

### 流程图

- 节点形状：开始/结束＝胶囊（深墨）；处理＝圆角矩形（白底 indigo 边）；判断＝菱形（amber 边/浅 amber 底）；循环＝圆角矩形 + 循环图标或菱形（teal）；输入/输出＝平行四边形（rose）；调用＝圆角矩形 + 电话/箭头图标（sky）；return/break/continue＝小胶囊（灰）。
- 文本最多两行，超出用省略；节点下可显示行号小字（`L12`）。
- 连线：2px 圆头，灰蓝 `#94a3b8`，箭头 6px；正交线用 8px 圆角；判断分支线上加小标签“真/假”或“是/否”（小胶囊，amber 文字）。回边（循环）用 teal 虚线 + “重复”标签。
- 布局：全树垂直居中，分支左右展开（真在左、假在右，靠标签说明；或按流程图惯例 yes 向下、no 向右；**统一即可**）；每个节点水平间距 ≥ 40，垂直间距 ≥ 32。孤立空函数 start→end 紧凑居中。
- 容器：白底点阵网格（极淡）作为画布，图例在左下（判断/循环/输入输出/调用），缩放按钮右上；`compact` 模式隐藏缩放、画布最小高 240。
- 交互：hover 节点浮起（阴影）、点击选中环；选中后底部显示代码片段（mono 小条）由外层实现；`activeLine` 高亮对应节点（indigo 外环）。
- 无障碍：`<title>`、节点 `role=button`。

### 调用图

- 节点卡：160×64 圆角 12，白底；顶部函数名（加粗 mono 13），底部类型/复杂度小字；main 用 indigo 实底白字；递归函数右上角 amber 小点 + “递归”；外部函数不建节点，在图下方以 “外部：printf / sqrt” chips 展示。
- 布局：从 roots 开始的层级图，左→右分层，同层纵向均分，边用 1.5px 贝塞尔曲线，箭头；递归边 amber 虚线回指，标“递归”；跨层长边可绕行。
- compact 高度 260；可横向滚动。
- 点击节点回调；选中节点显示 indigo 外环；node detail 由外层显示。

### 类图

- UML 风格盒子：宽 260–300；头部含 `«class»`/`«struct»`、类名（粗体 16）、行号；分隔线；字段区（`+ name: int`）、方法区（`+ area(): double`，虚函数斜体 + `virtual` 小字）。访问符用 `+ - #`。
- 基类在下方、派生类在上方？UML 惯例基类在上。用从上到下：基类 → 派生类，继承箭头从派生类指向基类（空心三角）。同级类横向排布；整体可滚动。背景白色，顶部色条 violet，抽象类名斜体。
- 空状态由外层处理。

### 内存布局

- 三块纵向区域：`全局 / 静态区`（sky 软底）、`栈区`（indigo 软底）、`堆区`（amber 软底，虚线）。每块左上角小组标题 + 字节数。栈区内每个函数帧为白底圆角框（函数名 + 行号）。变量格：小卡片，显示名称（mono 加粗）、类型、`n B`、值；数组拆成连续小格并标下标；指针格带 “→ 目标” 箭头图标。
- `compact` 时隐藏字节数细节、缩小间距；可横向滚动。
- 底部一行说明：`地址与布局为教学示意，不是真实运行地址。`

### 单步执行播放器

- 左代码 / 右状态。代码区：行号 + 语法高亮，当前行 indigo 透明高亮 + 左侧 3px 实条；执行到过的行可以淡色标记？不做，避免噪音。
- 右侧顺序：步骤描述（含事件 badge：声明/赋值/判断/调用/返回/输出）、变量监视表（名称、类型、值，变化行闪 amber 背景 600ms）、调用栈 chips、输出控制台（深色，等宽，自动滚动）。
- 控制条：⏮ / 上一步 / 播放暂停 / 下一步 / ⏭ + 滑块 + `3 / 42` + 速度（0.5×/1×/2×）。按钮 32×32 ghost，播放主按钮 indigo 实底。
- compact 模式：高度 ≤ 420，右侧仅显示描述 + 变量表前 8 个 + 输出折叠；控制条简化。
- 空/错误：友好图标 + 说明 + 建议（“试试把代码简化到解释器子集”）。
